# Kandinsky
Code for making kandinskys

## Features

- **Generative Art**: Creates unique, Kandinsky-inspired abstract artwork with every run.
- **Automatic Saving**: Automatically saves a high-resolution JPEG of the completed artwork to your downloads.
- **Fullscreen Mode**: Click the "Enter Fullscreen" button in the top-right corner to view the artwork in an immersive, fullscreen presentation mode. This is ideal for uninterrupted viewing.
